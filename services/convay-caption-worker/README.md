# Convay LM-05 caption worker (staged implementation)

Actual LiveKit Agents server, explicitly dispatched as `convay-captions`. Uses LiveKit Inference Speechmatics Linden-1 for configured English or Bengali. Subscribes only to microphone tracks after authorization, sends frames to streaming STT, persists final segments through the trusted gateway, and delivers text to explicitly authorized recipients. No simulated captions, no LLM/TTS, no audio or transcript files.

This worker is not a complete or activated production feature. Required integration: service-only `convay-caption-control` gateway implementing exact room/session/company/actor/track consent and quota authorization, short leases, immutable final segment persistence, recipient authorization, and worker job binding. The worker refuses capture if that gateway is absent or denies access. Its credentials must be configured only in the authorized worker environment. Complete a transitive dependency lock, worker deployment, client text-stream rendering, provider entitlement/capacity and actual English/Bengali multi-user acceptance before activation. Do not automatically dispatch this worker or enable a paid service. Existing four-person meeting cap and approved UI must be preserved.
